Privacy

This draft says what the marketing site and the Readiness Check will collect. It is not the policy, and it is not in force.

What this draft covers

The marketing site at abra-ca-dabra.app is static. It does not run an analytics script. The Readiness Check at check.abra-ca-dabra.app stores the answers you submit so it can show a band and four scores. That product educates and routes. It does not diagnose.

Analytics after consent

PostHog is the analytics tool the studio intends to use, and only after a visitor consents. This draft does not install a PostHog script. No pageview, click, or session is sent to PostHog from this site until a consent step exists and Christopher has approved this page.

The blog's Readiness Check links include a label so the check can record which note the visit came from. The label is part of the link. It is not a tracker on this page.
