About

We build software around how you work.

Abracadabra designs, builds and runs AI-powered tools for businesses whose work doesn't fit off-the-shelf software. Every system we ship comes with a short film of the real screens.

How we work

We start with how the work gets done today, write it down, and agree on it with you before anything is built. Then we build on Cloudflare, test on your real work, and keep the system running after launch.

Work we've shipped

  • Milrcorr: the website for StrongFoam's sister commercial fit-out business, where visitors see the work and request an estimate.
  • StrongFoam: a website where visitors can start an estimate and book.
  • Schema: see how easily AI search can find your site, and get the fixes.
  • LLM Leverage: a self-paced course for getting real work done with AI, plus workshops you can run.
  • Super Funnel: a sales app for independent associates, shown in eight short films.
