The shift

The answer’s already written down. Now you can find it.

The policy, the price, or the clause is already written. Reaching it means opening the wrong folder, asking the person who wrote it, or trusting a paragraph someone pasted into chat last month. The file and the answer drift apart, and two people give two versions of the same rule.

Search across a shared drive returns files, not the sentence. A general model returns a fluent paragraph that may not be your rule at all. You should not have to remember which folder holds the current rule. You get the current answer, the page it came from, and an honest ‘not in your files’ when it isn’t there.

The outcome

What you get

  • A plain question

    You or a customer ask the way you already talk. The file name is not required.

  • The page, attached

    The answer points at the page it came from, so you can open the sentence and read it.

  • The current file

    Update a policy and answers update with it.

  • An honest ‘I don’t know’

    If your documents do not contain the answer, we say so. We do not fill the gap with a general guess.

Where it earns its keep

Use cases

  • A policy lookup

    Someone asks what the rule is. The answer quotes the policy on file and links the page.

  • A part, a price, or a clause

    The question is specific. The reply comes from the sheet or the contract you already trust, with the line it used.

  • A staff question that should not wait

    Staff get answers right away, without interrupting you.

The operating model

How it works

From first conversation to a system that runs itself.

  1. Plan

    We map how the work gets done today, including the calls only a person should make, and agree on it before anything is built.

  2. Build

    Built on Cloudflare and connected to the tools you already use, so nothing has to move.

  3. Review

    Tested on your real work from last week before any customer sees it.

  4. Launch and run

    We launch with close monitoring, keep it running, and you can change the rules at any time. It’s yours to keep.

Questions, answered

FAQ

faq-title

Will it answer from the public internet?

No. This service reads the files you give it. Questions that live on the public web belong in search-grounded research, and the two stay apart.

What if two files disagree?

You pick which file is current. Until then, the answer shows both pages and does not pretend they say the same thing.

Can customers see internal files?

Only the set you mark for them. A staff handbook and a customer policy are different collections, and the question is asked against one of them.

Does it work on a scan?

If the scan has text that can be read, yes. If a scan can’t be read, it tells you instead of guessing.

Who decides which file is current?

You do. The system follows that mark. You decide which version is current, and answers follow it.

What does it cost?

Priced to the project, based on your files and how they’re used. Tell us what you need and we’ll quote it.
