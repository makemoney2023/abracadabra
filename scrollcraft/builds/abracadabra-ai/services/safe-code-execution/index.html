Safe execution of AI-written code

What it is

Some jobs ask a model to write a small program: a calculation, a file transform, a check. This runs that program in a closed box, so a mistake stays in the box.

What it looks like in your business

  • Turning a weekly spreadsheet into a calculated report, with the formula run in a box
  • Checking a file the model produced before anyone downloads it
  • Letting a teammate ask for a one-off calculation without handing over the keys to the business

How it works

  1. We decide which jobs may write code, and what that code is allowed to see.
  2. The code runs on Cloudflare, inside a sandbox, with no path to the rest of your systems unless you open one.
  3. The result comes back as a file or a number. The box is thrown away.
  4. You see what ran. You do not have to read the program to trust the boundary.

What you get

  • A sandbox for the jobs that need generated code
  • A list of what the code may read and write
  • The result of the run, and a record that it ran
  • A stop if the code asks for something outside the list

Who it's for

Owners who want the speed of generated code and a hard wall around everything else.

Signs you need it

  • A model is already writing snippets that someone pastes into a live tool
  • You want calculations on your files without uploading the whole business
  • You do not want a generated script sitting on a laptop with saved passwords

Built on Sandboxes, Containers. Built and deployed on Cloudflare's global network.

Questions

Can the code reach our email or our files?

Only the files you pass into that run. It does not inherit someone's login.

What if the code is wrong?

The box still contains it. You get the output to check, and a bad result does not change live records unless you built that step on purpose.

Do we review every program?

You review the job and the boundary. You do not have to review every line for the wall to hold.

Is this only for developers?

It is for any job where the useful output is a calculation or a file, and the risk is letting that program wander.
